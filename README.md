### 개발

정적 HTML이라 별도 빌드 과정은 없습니다. 파일을 수정한 뒤 `main`에 push하면 그대로 반영됩니다.

로컬에서 먼저 확인하려면 `node serve.js` 후 http://localhost:4173 을 여세요.

- `interactive.css` / `interactive.js` — 모든 문서가 공유하는 컴포넌트(읽기 모드, 비유 박스, 슬라이더, 해설 박스, 체크리스트)
- 각 문서의 고유 스타일과 시뮬레이터 로직은 해당 HTML 안에 인라인
